# 📈 InsightAI – AI Business Intelligence Assistant

InsightAI is an AI-powered Business Intelligence application built using **Google Gemini API** and **Streamlit**. It helps business users generate intelligent insights from CSV datasets in seconds.

## 🚀 Features

- 📂 Upload CSV datasets
- 📊 Interactive KPI Dashboard
- 📈 Sales & Profit Charts
- 🤖 AI-generated Executive Summary
- 📉 Trend Analysis
- ⚠️ Risk Detection
- 💡 Business Recommendations

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Pandas

## 📷 Demo

Upload a CSV file and click **Generate AI Insights** to receive:

- Executive Summary
- Key Trends
- Business Insights
- Risks
- Recommendations

## 📦 Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🔐 Environment Variable

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```
