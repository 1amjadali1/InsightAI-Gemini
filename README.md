# 📈 InsightAI – AI Business Intelligence Assistant

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://insightaidash.streamlit.app/)

An AI-powered Business Intelligence application built using **Google Gemini API**, **Python**, **Streamlit**, and **Pandas**. The application helps users transform raw business datasets into meaningful insights, executive summaries, and actionable business recommendations within seconds.

# 📌 Overview

Business users often spend hours analyzing reports and dashboards before making decisions.

InsightAI simplifies this process by combining traditional Business Intelligence with Generative AI.

Simply upload a CSV file and InsightAI automatically generates:

- Executive Summary
- KPI Analysis
- Sales & Profit Dashboard
- Trend Analysis
- Risk Identification
- AI-Powered Business Recommendations

using **Google Gemini AI**.

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/1amjadali1/InsightAI-Gemini.git
```

Go to project

```bash
cd InsightAI-Gemini
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run the application

```bash
streamlit run app.py
```

# 🤖 How It Works

1. Upload CSV dataset
2. Data is processed using Pandas
3. KPI metrics are calculated
4. Charts are generated
5. Dataset summary is prepared
6. Google Gemini analyzes the dataset
7. AI generates business insights and recommendations
